# AI辅助开发标注

本项目遵循「人类主导设计与决策、AI（TRAE）辅助实现与加速」的协作模式。以下逐模块标注人工与 AI 的分工及复核方式。

## 一、人工完成（设计决策与质量控制）

1. **需求拆解与技术选型**：通读 B 级测试单，确定「零依赖 Node 原生栈 + 双 Serverless 适配 + 本地 JSON 会话存储」方案，确保评审 15 分钟内可运行。
2. **四入口角色分化与技术观测面板的产品决策**：对比一等奖作品后，人工决策设置「用户入口（学生/家长）/ 教师入口 / 企业/机构入口 / 技术人员/管理入口」四通道：前三者免密自选身份、仅影响界面主题与应答语气，技术人员入口口令校验、独享检索追踪/会话日志/知识库状态三页签观测面板；人工定义「同接口按角色分级返回 trace」的交互方式与暖/冷双风格分化（用户入口米色暖调活泼风、其余入口淡蓝理性专业风），以可视化方式呈现技术深度。
3. **鉴权方案定级**：明确为演示级（口令 + HMAC-SHA256 时效令牌），划定安全边界（恒时比较、7 天过期、密钥不落仓库），并在文档中如实标注与生产级方案的差距。
4. **知识库结构设计**：人工通读三份课程素材（夏令营手册/教师培训体系/平台白皮书），决定按「章 → 主题块」切分为 36 个知识块，逐块撰写关键词列表；确定 zone（camp/teacher/platform）三区隔离与跨区回落策略。
5. **提示词规则定义**：知识边界（只依据摘录、禁编造、强制来源标注）、咨询引导（单次澄清、会话记忆沿用）、入口角色基调（用户/教师/企业三类入口的语气与侧重）、动态身份策略（家长/初中/高中/教师/企业五类画像）均为人工逐条拟定。
6. **测试用例设计**：37 组用例（功能 20 / RAG 7 / 前端 7 / 部署 3）的输入、预期与判定标准由人工设计，含反编造陷阱题（虚构「马甸桥教学点」）与鉴权安全用例（错误口令、未知角色、无令牌与跨角色越权、令牌篡改）。
7. **UI 视觉决策**：教育蓝金配色、顾问头像元素（书本+AI 字样、无医疗符号）、底部固定区高度控制、登录门禁四卡布局与暖/冷风格分化（用户入口米黄打底+红/绿/黄点缀，其余入口淡蓝理性风）、移动端单列与观测面板收窄规则等由人工指定。

## 二、AI 辅助完成（代码与文档初稿）

1. `lib/retrieval.js`（区路由 + 二元组切词 + IDF-lite 加权）、`lib/prompt.js`、`lib/handler.js`、`lib/store.js`、`lib/auth.js`、`server.js` 的代码初稿。
2. `public/index.html` 的样式与交互脚本（登录门禁、气泡、抽屉历史、观测面板三页签、打字动画、语音输入降级）。
3. 部署脚本（Netlify/Vercel REST API digest 部署）与测试脚本骨架。
4. README、系统架构说明等文档初稿。

## 三、人工复核与关键修正记录

1. **全部代码逐行人工审阅**，重点核对：路由词表边界、错误返回格式与测试单示例一致（`{code, message}`）、令牌签名与校验逻辑、密钥不落仓库。
2. **检索排序缺陷修复**：真机测试发现「教师培训L1学什么」误排（公共概述块挤掉 L1 专属块）。人工定位为「区公共词（教师/培训）无区分度」，决策引入 IDF-lite 降权，修复后冒烟断言全过。
3. **Serverless 容器隔离缺陷修复**：功能增强后的公网实测发现 F5（对话记录保存）/F6（历史查询）失败——人工定位为 Netlify 多函数容器隔离（内存与 /tmp 互不共享），决策将 4 个函数收敛为 `netlify/functions/api.js` 单函数统一入口并为 store 增加进程内内存层，复测公网 31/31 全过。该过程完整留痕于《开发过程记录》。
4. **37 组真机测试输出逐条人工核验**：数字（6980/5980/8课时等）与素材原文逐一比对，拒答话术、四角色签发与越权拒绝、trace 分级返回均符合预期（本地 36 通过 + 1 项公网复测随部署窗口补测）。
5. **移动端样式缺陷修复**：真机发现「后置基础样式覆盖媒体查询」导致窄屏入口卡挤压、观测面板越界，人工定位 CSS 规则顺序根因并修复，390px 视口复测通过。
6. **部署凭证管理**：Netlify/Vercel 个人访问令牌与管理员口令由人工持有与注入，代码与仓库仅含 `.env.example` 模板，无任何明文密钥。

## 四、AI 使用边界声明

- AI 不接触任何真实用户数据；测试数据均为构造用例。
- 知识库内容 100% 源自主办方提供的三份素材，AI 仅做结构化整理，未增删事实。
- 所有对外提交内容（含本文档）经人工终审后发布。
