# 演示说明（三分钟体验路线 + 大白话技术解读）

> 面向评审、工作人员与路演现场：第一部分是怎么点、看什么；第二部分是「这背后是怎么回事」的大白话解读，可直接口述。

## 一、三分钟体验路线

**入口**（任选其一，功能一致）：

- 公网演示：<https://ai-course-advisor-b445432.netlify.app>

- 本地一键：`node server.js` 后打开 <http://localhost:3000> （零依赖，无需 npm install）

- 说明：公网与本地均为四入口角色版（同一套代码，公网已全量复测 37/37 通过）。

**第 1 分钟｜四入口分流**

1. 打开链接，首屏是四张入口卡：用户入口（学生/家长）、教师入口、企业/机构入口、技术人员/管理入口。
2. 注意视觉差异：用户入口是米色暖调 + 红/绿/黄点缀的活泼风；其余三张是淡蓝理性专业风。
3. 手机访问同一链接：四张卡自动竖排单列，不挤压。

**第 2 分钟｜角色化问答**

1. 点「用户入口」免密进入：欢迎区话题卡是家长最关心的（班型/费用/安全/零基础）。点一张话题卡或直接问「我孩子初一，零基础能跟上吗？」——AI 以家长视角作答，附来源标注（《文档名》·章节）。
2. 返回登录页换「教师入口」：话题卡换成 L1-L3 路径/课时/证书，问「L1 学什么？多少课时？」——专业高效的教师视角。
3. 试一道「陷阱题」：问「夏令营在马甸桥有教学点吗？」——资料中没有，AI 明确说不编造，并给出资料里真实的班型地点。

**第 3 分钟｜技术观测（技术人员/管理入口）**

1. 回登录页点「技术人员/管理入口」，输入框下方已标注演示口令 `opc2026-review`，照输、点「验证并进入」（一次登录 7 天有效）。
2. 点右上角「技术观测」：三个页签——检索追踪（每次请求翻了哪个分区、检索词、命中块得分）、会话日志、知识库状态（36 块清单）。
3. 再以技术人员身份提问，回答下方会多出一个「检索过程回放」，黑盒变透明。

## 二、大白话技术解读（答辩/路演可直接讲）

**Q1：登录和角色入口是怎么工作的？**

- 四入口 = 展厅的四道门：学生/家长、教师、企业三道门敞开进（免密），进门发一张对应颜色的「身份卡」；技术人员那道门要刷工作证（口令）。门只决定装修风格和管家说话方式，不决定你能不能看别人的账本。

- 身份卡（登录令牌）= 游乐园手环：盖防伪章（HMAC-SHA256 签名）、印着有效期（7 天）；手环仿造不了、过期作废，颜色（角色）也压进防伪章里，自己改颜色立刻露馅。

**Q2：我发出一句话，到收到回答，中间发生了什么？**

- 像去图书馆问管理员：① 先看手环颜色，决定用什么语气；② 听问题判断去哪个楼层（夏令营/教师培训/平台三分区，防止张冠李戴）；③ 在楼层里按「稀有词优先」找资料（「L1」比「培训」更指路）；④ 找最相关的 5 页摊桌上，只许照资料写答复；⑤ 末尾贴上「出自哪本资料哪一章」；⑥ 全程登记（耗时、翻哪几页、各打多少分），技术人员可随时回放。

**Q3：为什么要按角色分开？**

- 像有经验的课程顾问：对家长先讲安全和费用（温暖耐心），对教师先讲分层路径（专业高效），对企业先讲合作方案（务实清晰）——同一个知识库，不同的服务方式。

- 双保险：除进门选的身份，系统还从你说的话里再识别一次身份（「我孩子初一」→ 自动按家长+初中学段作答），两层叠加答得更准。

**Q4：数据和密钥安全怎么保证？**

- 钥匙不进仓库：密钥与口令只存服务器「保险柜」（环境变量），仓库只有空钥匙模板（.env.example）。

- 账本分权：检索追踪/会话日志/知识库状态只有技术人员手环能看，其余角色一律 401 拦截。

- 资料不外传：知识库 100% 源自主办方三份素材；会话有上限（单会话 100 条、全局 200 会话自动淘汰）。

- 不编造是硬规矩：资料里没有的直接说「没有」，附真实信息引导。

**Q5：技术亮点一句话版（评委追问时备用）**

- 「三区路由 + 中文二元组 + IDF-lite 降权」的自研轻量检索，36 块知识库零向量依赖、可解释可调分；

- 「分区摘录 + 入口基调 + 身份画像」三层动态提示词注入；

- 同接口按角色分级返回 trace，检索过程全程可回放；

- Netlify 单函数统一入口解决 Lambda 容器隔离丢会话问题，本地与公网同一套业务核心；

- 37 组真机测试电池（功能 20 / RAG 7 / 前端 7 / 部署 3），含反编造陷阱题与越权安全用例。
